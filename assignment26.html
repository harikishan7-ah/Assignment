CSS Box Model - Annotated

This page explains the four layers of a CSS element.

1. Actual Element

My Box

The element has a content width of 200px, content height of 80px, padding of 20px, border of 10px and margin of 30px.

2. Annotated Diagram

Margin: 30px
Border: 10px
Padding: 20px
Content 200 × 80px

3. Size Calculation

Measurement Calculation Result
Total width without margin 200 + 40 + 20 260px
Total width with margins 260 + 60 320px
Total height without margin 80 + 40 + 20 140px
Total height with margins 140 + 60 200px

4. Box Sizing

By default, CSS uses box-sizing: content-box. Width and height apply to the content only.

With box-sizing: border-box, the declared width and height include content, padding and border. 

* {
    box-sizing: border-box;
}
