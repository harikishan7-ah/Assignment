Design Choices

Colour: Deep blue represents trust and professionalism. Orange highlights buttons and important actions.

Typography: The system font stack loads quickly and provides readable text. A line-height of 1.6 improves readability.

Layout: The content width is limited to 800px. White cards on a light background create a clean and organised appearance.

Navigation: The navigation links use HTML fragment links such as #home and #about to display each section.

Responsiveness: A media query adjusts the layout for smaller screens such as mobile phones.

Maintainability: CSS variables store the main colours and border radius so they can be changed in one place.
